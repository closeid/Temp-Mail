# Get an Email frontend

Cloudflare temporary email frontend built with Vite, React, React Router, TanStack Query, Tailwind CSS, shadcn/ui-style components, and Radix UI primitives.

## Project setup

```bash
pnpm install
```

### Development

```bash
pnpm dev
```

### Production build

```bash
pnpm build
```

### Tests

```bash
pnpm test
pnpm test:e2e
```
